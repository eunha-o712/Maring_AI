# 3D prototype archive

This folder contains the first Blender/GLB exploration. It does not match the approved Maring character closely enough and is not loaded by the Flutter app.

The active character direction is the transparent 2.5D expression set in `maring-frontend/assets/maring/`. Keep this folder only as modeling research and an export-pipeline reference. Do not treat `output/maring.glb` as a production asset.
