# 마링 2.5D MVP 검증 기록

검증일: 2026-09-06, 성장 확장 2026-09-07 (Asia/Seoul)

## 결과 요약

원본 캐릭터 기반 2.5D 표정 9종을 앱 전 화면에 연결했고, 작은 구름 씨앗부터 별빛 수호 단계까지 크기와 색이 변하는 성장 자산 5종을 추가했다. 로컬 Spring Boot API와 Flutter web 앱을 함께 실행해 신규 사용자 전체 흐름을 통과했다.

## 자동 검증

| 항목 | 결과 |
|---|---|
| `tools/test-flutter.ps1` | 11개 테스트 통과 |
| `flutter analyze --no-pub` | 이슈 0개 |
| `flutter build web --no-pub --output=build/web-app` | 성공 |
| `flutter build apk --debug --no-pub` | 성공 |
| `mvn -B test` | 백엔드 7개 테스트 통과 |
| `git diff --check` | 공백 오류 없음. Windows 줄바꿈 안내만 발생 |

Android 디버그 APK는 `maring-frontend/build/app/outputs/flutter-apk/app-debug.apk`에 생성되었다. 디버그 엔진이 포함된 개발용 파일이므로 크기는 출시 번들 크기를 뜻하지 않는다.

## 실제 브라우저/API 전체 흐름

로컬 `application-local.yml` 프로필과 일반 앱 웹 빌드를 사용했다.

1. 새 사용자 `QA마링`을 만들고 INFP/존댓말을 선택했다.
2. 부화 화면에서 1단계 `구름 씨앗` 2.5D 캐릭터와 완료 문구를 확인했다.
3. `sad`, 강도 3으로 체크인했다.
4. 홈의 대표 캐릭터가 `sad`로 바뀌는 것을 확인했다.
5. 마음 기록 달력에서 해당 날짜의 작은 2.5D 캐릭터, `6일 슬픔, 강도 3` 접근성 라벨과 상세 캐릭터를 확인했다.
6. 일반 메시지에 존댓말 규칙 기반 공감 응답이 오는 것을 확인했다.
7. 위기 테스트 문장에 고정 안전 응답이 우선하며, 안전 오버레이에 109·1577-0199·1388·1366 네 자원이 각각 전화 버튼으로 표시되는 것을 확인했다.

브라우저 검증에서는 실제 전화 앱을 열지 않았다. `tel:` 연결은 Flutter 위젯/빌드 단계까지 검증했으며, 통화 가능한 Android/iOS 실제 기기에서 마지막 수동 확인이 필요하다.

## 성장 화면 시각 검증

2026-09-07에 캐릭터 미리보기 웹 빌드에서 성장 여정 화면을 추가로 확인했다.

- 구름 씨앗에서 별빛 수호까지 5개 단계가 작은 몸집에서 큰 몸집 순서로 표시된다.
- 진주빛·라일락에서 로즈·바이올렛·샴페인 골드로 이어지는 색상 변화와 최종 단계의 엔젤링·망토가 구분된다.
- 잠긴 단계, 현재 단계 강조, 체크인 임계값과 다음 성장까지 남은 일수가 데스크톱 뷰포트에서 잘림 없이 표시된다.
- 작은 휴대폰 레이아웃은 위젯 테스트에서 스크롤 가능성과 오버플로 부재를 확인했다.

## 자산 검증

- 표정 9개와 성장 5개 앱 PNG가 모두 1024×1024 RGBA이며 네 모서리 알파 값이 0이다.
- 표정별 전체 실루엣, 엔젤링, 가슴 엠블럼과 손·발 위치를 공통 정체성으로 유지했다.
- 달력과 준비 중 화면도 플랫폼별로 깨질 수 있는 이모지 대신 2.5D 캐릭터/Material 아이콘을 사용한다.
- 전체 시각 비교본은 `docs/maring-2.5d-contact-sheet.png`, 생성 프롬프트는 `docs/character-assets.json`에 있다.
- 성장 비교본은 `docs/maring-growth-contact-sheet.png`, 단계·색상·임계값·프롬프트 기록은 `docs/maring-growth-system.md`에 있다.
