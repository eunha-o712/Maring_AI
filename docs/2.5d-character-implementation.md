# 마링 2.5D 캐릭터 적용 기록

## 결정

앱 캐릭터는 GLB 3D 모델 대신 투명 PNG 기반 2.5D 스프라이트를 사용한다. 원본 캐릭터의 둥근 실루엣, 작은 보석형 눈, 분홍-라벤더 그라데이션, 엔젤링과 가슴의 마음 링을 정체성 기준으로 삼는다. 기존 `3d-model/output/maring.glb`는 미사용 프로토타입이다.

## 완료된 자산

모든 앱 자산은 `maring-frontend/assets/maring/`에 있는 1024×1024 RGBA PNG다.

| 파일 | 용도 | 감정 카드 매핑 |
|---|---|---|
| `neutral.png` | 기본·첫 인사 | 기본 |
| `joy.png` | 기쁨 | `joy` |
| `calm.png` | 평온 | `calm` |
| `sad.png` | 슬픔 | `sad` |
| `anxious.png` | 불안 | `anxious` |
| `angry.png` | 화남 | `angry` |
| `empathy.png` | 공감·외로움 | `lonely` |
| `thinking.png` | 생각 중·혼란·응답 대기 | `confused` |
| `tired.png` | 지침 | `tired` |

생성 프롬프트는 `docs/character-assets.json`, 한눈에 보는 시트는 `docs/maring-2.5d-contact-sheet.png`에 보관한다. 새 자산은 `tools/normalize-maring-assets.ps1`로 캔버스와 표시 크기를 맞추고 `tools/build-character-contact-sheet.ps1`로 시트를 다시 만든다.

성장 자산 5종과 체크인 기반 성장 규칙은 `docs/maring-growth-system.md`, 비교 시트는 `docs/maring-growth-contact-sheet.png`에 보관한다.

## 앱 적용

- `MaringCharacter`가 표정 전환, 은은한 글로우, 호흡 애니메이션을 공통 처리한다.
- 기기의 동작 줄이기 설정과 비활성 탭의 `TickerMode`를 따른다.
- 스플래시, 온보딩, 부화, 홈, 체크인, 채팅, 마음 기록에 캐릭터를 연결했다.
- 부화는 1단계 구름 씨앗으로 시작하고, 홈은 누적 체크인 0·3·7·14·30일에 맞춰 5단계로 성장한다.
- 홈은 오늘의 체크인 감정을 표시하고, 별 버튼으로 전체 표정 갤러리를 연다.
- 채팅은 응답 대기 중 `thinking`, 평상시 `empathy`를 사용한다.
- 안전 안내의 상담 자원은 전화 가능한 기기에서 `tel:` 연결을 연다.
- `MARING_CHARACTER_PREVIEW=true` 빌드 설정으로 표정 갤러리를 바로 실행할 수 있다.

## 검증 기준

- 9개 파일이 1024×1024이며 네 모서리 알파가 0이어야 한다.
- `flutter analyze --no-pub`가 경고 없이 끝나야 한다.
- `tools/test-flutter.ps1`가 이미지 디코딩·투명도, 작은 화면 온보딩, 갤러리 전환, 세션 복구 테스트를 통과해야 한다.
- `flutter build web --no-pub`와 Android debug APK 빌드가 성공해야 한다.
- 루트에서 `mvn -B test`가 API 전체 흐름과 안전 분류 테스트를 통과해야 한다.
